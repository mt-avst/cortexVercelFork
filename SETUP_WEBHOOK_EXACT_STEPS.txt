EXACT STEPS TO CONFIGURE VERCEL-GITHUB WEBHOOK
================================================

STEP 1: Open Vercel Git Settings
--------------------------------
URL: https://vercel.com/nicks-projects-113886a0/adapta-labs-p62q/settings/git

STEP 2: Check Current Status
-----------------------------
You should see one of:
- "Connect Git Repository" button (if disconnected)
- Your repository listed as "Connected" (if connected but webhook not working)

STEP 3: Connect/Reconnect GitHub
----------------------------------
If you see "Connect Git Repository":
- Click it
- Select "GitHub"
- If asked to authorize, click "Authorize Vercel"
- Select your repository: nickfine/AdaptaLabs
- Click "Deploy"

If you see it's already connected:
- Look for a "..." menu or "Disconnect" button
- Click it and choose "Disconnect"
- Then click "Connect Git Repository"
- Follow the steps above

STEP 4: Verify Auto-Deploy
---------------------------
After connecting, on the same page, scroll down to find:
"Production Deployments" section
Make sure "Auto-deploy from GitHub" is ON (green/toggled)

STEP 5: Verify Webhook was Created
------------------------------------
Go to: https://github.com/nickfine/AdaptaLabs/settings/hooks

You should see a webhook listed there
The URL should contain "vercel.com"
The recent deliveries should show successful requests

STEP 6: Test It
---------------
Once the webhook is set up, run this command:
git commit --allow-empty -m "Test webhook connection" && git push

Within 30 seconds, check Vercel dashboard - you should see a new deployment!
