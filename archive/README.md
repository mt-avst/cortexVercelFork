- **deployment-and-status/** — Deployment status, Vercel/GitHub setup, alpha readiness, status summaries
- **code-reviews/** — Code consistency and integrity review snapshots
- **summaries-and-fixes/** — Fix summaries, audit completions, runbooks, milestone notes
- **planning/** — Redundant planning docs (core.md duplicate of plan.md, milestone task lists tasks_m*.md)
- **misc/** — Cookie/debug text files, webhook setup steps, session notes

These are kept for reference only; for current guides see the root `README.md`, `TESTING_GUIDE.md`, and `docs/`.
